# Manual Verification Checklist Before Phase 17

آخر تحديث: 2026-06-03

هذا الملف هو مكان الاختبار اليدوي الرسمي قبل فتح Phase 17 الخاصة بـ `tasks`, `expenses`, و`inventory`.

لا تبدأ Phase 17 إلا بعد تنفيذ اختبارات `P0` وتوثيق نتيجتها هنا أو في نسخة من هذا الملف.

## قاعدة النجاح

| المستوى | المعنى | قرار Phase 17 |
|---|---|---|
| P0 | اختبار حرج للـ shopping MVP أو حماية البيانات | أي فشل يمنع Phase 17 |
| P1 | اختبار مهم لتجربة local-first الكاملة | يفضل إصلاحه قبل Phase 17 |
| P2 | تحسين أو تغطية إضافية | لا يمنع Phase 17 إذا كان موثقاً |

## تجهيز الاختبار

استخدم جهاز حقيقي أو Emulator ثابت. الأفضل جهازان أو جهاز + Emulator لاختبارات Realtime.

### بيانات مطلوبة

- مستخدم A: `tester_a`
- مستخدم B: `tester_b`
- منزل مشترك بين A و B.
- قائمة تسوق باسم `Manual Test List`.
- عناصر أولية:
  - `Milk`
  - `Bread`
  - `Rice`
- تصنيف مخصص باسم `Manual Category`.
- وحدة مخصصة أو موجودة باسم `kg` أو `piece`.

### أوامر تحقق قبل البدء

```bash
supabase status
supabase migration list --local
supabase db lint --local
/home/omar/flutter/bin/flutter analyze
LD_LIBRARY_PATH=/tmp/sqlite3_lib:$LD_LIBRARY_PATH /home/omar/flutter/bin/flutter test
```

النتيجة المتوقعة حالياً:

- `supabase db lint --local`: لا توجد أخطاء.
- `flutter analyze`: لا توجد مشاكل.
- `flutter test`: كل الاختبارات تمر.

### تشغيل التطبيق

```bash
/home/omar/flutter/bin/flutter run
```

لتبديل الإنترنت استخدم Airplane Mode من الجهاز، أو من Android:

```bash
adb shell svc wifi disable
adb shell svc data disable
adb shell svc wifi enable
adb shell svc data enable
```
