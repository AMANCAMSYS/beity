## ما هو جديد في هذا الإصدار

### الميزات الأساسية المتاحة

- **المصادقة**: تسجيل دخول/خروج وإنشاء حساب بالبريد الإلكتروني
- **المنازل**: إنشاء وإدارة منازل متعددة
- **الأعضاء والدعوات**: دعوة أعضاء بإيميلاتهم، إدارة الأدوار (مالك/مدير/عضو/مشاهد)
- **قوائم التسوق**: إنشاء وتعديل وأرشفة وحذف القوائم
- **عناصر التسوق**: إضافة وتعديل وحذف وشراء العناصر مع اقتراحات تلقائية
- **وضع التسوق**: وضع خاص للتسوق في المتجر مع تجميع بالتصنيف وشريط تقدم
- **المزامنة اللحظية**: تحديثات فورية عبر Supabase Realtime مع Presence
- **سجل النشاطات**: تتبع شامل لجميع العمليات
- **الإشعارات**: إشعارات داخل التطبيق مع إعدادات التفضيلات
- **التصنيفات**: إدارة تصنيفات التسوق (افتراضية + مخصصة)
- **وحدات القياس**: إدارة وحدات القياس (افتراضية + مخصصة)
- **الملف الشخصي**: تعديل الاسم ورقم الهاتف

### الميزات المخفية (خلف أعلام الميزات)

هذه الميزات مكتملة الكود لكنها مخفية في هذا الإصدار:

- **المهام** (`enableTasks: false`): إدارة المهام مع الإسناد والتكرار والأرشفة
- **المخزون** (`enableInventory: false`): تتبع مخزون المنزل مع تنبيهات الحد الأدنى
- **المصروفات** (بدون مسار): تتبع المصروفات والتسوية بين الأعضاء

لتفعيل هذه الميزات، عدّل `lib/core/config/feature_flags.dart`.

## ما لا يعمل بعد

### قائمة الانتظار دون اتصال

الكود الخاص بقائمة الانتظار دون اتصال موجود لكنه **غير مربوط** بتدفق التسوق الحالي. التطبيق يعمل فقط عند وجود اتصال بالإنترنت. لا توجد مزامنة تلقائية بعد استعادة الاتصال.

**الحالة**: جزئي - يحتاج ربط `OfflineAwareShoppingRepository` بـ Providers.

### الانضمام بالرمز

زر "الانضمام إلى منزل" في شاشة الترحيب تم إخفاؤه لأن التنفيذ غير مكتمل. الأعضاء الجدد يمكنهم الانضمام عبر رابط الدعوة فقط.

### تعديل التصنيفات والوحدات

أزرار التعديل على التصنيفات والوحدات المخصصة تم إخفاؤها. يمكن حذف التصنيفات/الوحدات المخصصة فقط.
